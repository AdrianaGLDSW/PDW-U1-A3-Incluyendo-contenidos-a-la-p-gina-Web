Elementos básicos de una página web.

¿Qué es lenguaje HTML y para qué sirve?

El lenguaje de Marcado de Hipertexto (HTML) es el código que se utiliza para estructurar y desplegar una página web y sus contenidos, onsiste en una serie de elementos que usarás para encerrar diferentes partes del contenido para que se vean o comporten de una determinada manera.

HTML realmente no es un lenguaje de programación, si no un lenguaje de marcado. Esto sirve para estructurar el contenido de una web a través de etiquetas. El HTML se trabaja en la parte frontend de una web, es decir, la parte que se encarga del diseño web y es la que ve el usuario.

Estructura básica de una página web HMLT 5.

En HTML 5, la estructura básica de la página web se organiza de la siguiente manera:.

  1. <!DOCTYPE html>.Define el tipo de documento HTML 5.

    2. Debe ir especificado siempre para que el navegador sepa de que tipo de documento HTML se trata.

  2. <html lang= "es">.Es la raiz del documento HTML y describe el idioma.
  3. <head>. Etiquetas de encabezado <head>. Contiene metadatos sobre el documento, como título, tipografías, los enlaces a los archivos de estilos (css), javascript (js) etc.

    4. Es la sección donde se incluyen metadatos (información sobre el documento), como el título, el conjunto de caracteres, y enlaces a archivos CSS y scripts.

    Ejemplos:

    <head>

    • <meta charset="UTF-8">
    • <meta name="viewport" content="width=device-width, initial-scale=1.0">
    • <title>Mi página web</title>

    </head>

    En donde el:

    • <meta charset="UTF-8"> Esta estiqueta especifica la codificación de caracteres para el documento, indicando que se debe usar UTF-8.
    • <meta name="viewport" content="width=device-width, initial-scale=1.0"> Esta etiqueta nos ayuda a la hora de implementar un diseño responsivo en nuestra pagina.

  4. <title>.Define el título de la página, que aparece en la pestaña del navegador.
  5. <body>.Contiene el contenido visible de la página.

Anatomía de un elemento HTML

Un elemento HTML se compone de una etiqueta de apertura, contenido y una etiqueta de cierre.

  • Etiqueta de apertura:

    • Consiste en que el elemento sea encerrado por paréntesis angulares (< >) de apertura y cierre. Ejemplo: el elemento párrafo <p>, establecerá donde comienza a tener efecto dicho elemento, en este caso donde comienza el párrafo.

  • Etiqueta de cierre:

    • Es igual que la etiqueta de apertura, excepto que incluye una barra de cierre (/) antes del nombre de la etiqueta. Sintaxis: </p>

  • Contenido:

    • Este representa el contenido del elemento, que en este caso es sólo texto. Ejmeplo:<p>Hola mundo</p>, el contenido del elemento párrafo es: Hola mundo.

  • Elemento:

    • La etiqueta de apertura, más la etiqueta de cierre, más el contenido equivale al elemento.

Algunas de las etiquetas mas empleadas para el contenido son las siguientes:

<blockquote> Representa un contenido citado desde otra fuente.
<ol> Especifica una lista ordenada de elementos.
<ul> Determina una lista de elementos sin orden.
<li> Define un elemento de una lista.
<di> Especifica una lista de definiciones, es decir, una lista de términos y sus definiciones asociadas.
<dt> Representa un término definido por el siguiente <dd>
<dd> Indica la definición de los términos listados antes que él.
<figure> Agrupa cualquier contenido que forme parte de un bloque o unidad independiente de información visual o multimedia, que puede ir acompañado de una descripción <figcaption>. Esto incluye imágenes, videos, audios, y cualquier otro tipo de contenido relacionado.
<figcaption> epresenta la leyenda o título de un elemento <figure>

Etiquetas y su explicación.

Las etiquetas HTML son las palabras que están dentro de un corchete, por ejemplo: <title>. Estas etiquetas crean una estructura jerárquica, es decir, se anidan entre ellas.

Además de las etiquetas, también contamos con los atributos. Estos sirven para añadir más información a una etiqueta.

Ejemplo:

<a href=”https://www.udgvirtual.udg.mx/cas/login?service=https%3A//www.udgvirtual.udg.mx/cas%3Fdestination%3Duser” target="_blank">Iniciar sesión en UDG Plus</a>

Siguiendo con este ejemplo, <a> sería la etiqueta y href y target, los atributos. El atributo href está indicando que es la URL de una página que hemos enlazado y el atributo target le está diciendo que la abra en una pestaña distinta del navegador cuando el usuario haga clic.

Entre las etiquetas para el diseño de página HTML, encontramos html, head y body, que conforma la estructura básica de una web. Además, contamos con otros elementos que aportarán mayor información sobre la página como la etiqueta meta, title y link.

Ejemplo:

  • Información de la página web: <head></head>
  • Cuerpo de la página: <body></body>
  • Información: <meta>
  • Título de la página web: <title></title>
  • Elemento básico: <html></html>

Estos son algunas de las etiquetas para construir los párrafos, enlaces, título, etc.

Ejemplo:

  • Títulos: <h1> </h1> a <h6> </h6>.
  • Imagen:<img>
  • Párrafos: <p>
  • Enlaces:<a><</a>
  • Negritas: <strong><strong/>, <b></b>
  • Elementos nulos: <hr/> y <br/>
  • Listas:
    1. Ordenadas:<ol>
    2. Desordenadas: <ul>

      3. Para cada elemento de la lista se emplea la etiqueta <li>

Elementos de encabezado HTML.

Los elementos de encabezado implementan seis niveles de encabezado del documento, <h1> es el más importante, y <h6>, el menos importante. Un elemento de encabezado describe brevemente el tema de la sección que presenta.

El propósito de esta etiquetas es la jerarquía.

Nota: considerar que tener más de un h1 es mala práctica y además no se debe saltar ningún nivel.

Elemento párarfo.

Esta etiqueta sirve para separar párrafos. Su importancia radica en que un ordenador no distingue si estos se escriben separados.

Listas ordenadas <ol> y desordenadas <ul>.

En HTML, se pueden enumerar elementos en forma ordenada o desordenada. Una lista ordenada utiliza números o algún tipo de notación que indica una serie de elementos.

Las listas ordenadas <ol> enumeran los elementos, mientras que las desordenadas <ul> son listas con viñetas.

Ejemplo de listas ordenadas Ejemplo de listas desordenadas

<ol>

<li>Primer elemento de la lista</li>

<li>Segundo elemento de la lista</li>

<li>Tercer elemento de la lista</li>

</ol>

<ol>

<li>Primer elemento de la lista</li>

<li>Segundo elemento de la lista</li>

<li>Tercer elemento de la lista</li>

</ol>

Para crear una lista ordenada se debe emplear la etiqueta <ol>. Dentro de los elementos de la lista ordenada se deben de definir los elementos que conformaran la lista, y esto se hace dentro de las etiquetas de aparetura y cierre: <ol> </ol>

Para defirnir cada uno de los elementos que integran la lista se usa la etiqueta <li></li>.

Esta misma sintaxis se emplea en las listas desordenadas, solo que en este caso se emplea la etiqueta <ul></ul>.

Otras etiquetas para diseñar páginas web HTML 5.

Además de las que hemos comentado antes, para darle un poco de forma al contenido, utilizamos otros tipos de etiquetas, como tablas, secciones y liks.

Ejemplo:

  • Secciones:<div></div>
  • Tablas:<table></table>
  • Enlaces: <a></a>
Entornos de desarrollo o editores

Un editor de HTML se emplea para escribir la base del sitio web.

Podríamos utilizar un simple bloc de notas para escribir HTML, es útil utilizar un editor código más avanzado.

Algunos ejemplos son:

  1. Notepad++: este editor se distribuye como software libre y su repositorio también está disponible en GitHub. Al igual que otros proyectos de la comunidad, admite plugins de terceros.
  2. Visual Studio Code: es el más utilizado por los desarrolladores. Es de código abierto y gratuito, además es muy potente. Tiene muchas extensiones y gran soporte para gran variedad de lenguajes como .NET Así que ya sabes cómo crear una página web en HTML, ahora es el momento de poner tus habilidades en práctica.
  3. CodePen:es un editor web de código HTML, CSS y JavaScript que le permite probar el código directamente en el navegador.
  4. Atom:se trata de uno de los mejores editores de HTML, gratuito y de código abierto, y fue desarrollado por el equipo de GitHub. Atom usa una licencia de software libre para su paquete y es mantenida por la comunidad de GitHub.
